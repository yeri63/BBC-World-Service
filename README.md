News feed from BBC World Service with reports from around the world every 15 seconds.

I've always wanted to have a ticker news feed like the moving LED display at Times Square in New York City, but keep getting sidetracked with other projects which take less time to complete, or have an immediate need, pushing this idea further back in the queue. 

To make a step in this direction, why not work out the logic, and test this idea out using built-in displays on the Cisco IP Phones I had throughout the house. This saved me the cost of purchasing LED matrix displays and developing the code to run on a ESP8266 with WiFi, long before the ESP32 chips were available. The only cost was my time. This application is the fruit of that labor.
