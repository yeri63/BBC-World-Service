<p>I've always wanted to build a ticker news feed like the moving LED display at Times Square in New York City, but kept getting sidetracked with other projects which took less time to complete, or had an immediate need, pushing this idea further back in the queue.</p>
<p>My idea was to purchase multiple LED matrix displays with enough characters visible at one time to produce a readable message, and connect them to a ESP8266 using WiFi to collect news online. It would be compact, and look simply like a message board, with just a power connection. This was long before the ESP32 boards were available. There had to be another alternative in the meantime...</p>
<p>To finally take a step forward, I decided to focus on the logic and build a software based solution, using the built-in LCD displays available on Cisco IP Phones to show the news stories. The only cost now was time. This application is the fruit of that labor.</p>
